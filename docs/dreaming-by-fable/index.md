# dreaming을 하네스에 쓰는 방안 분석

Anthropic의 dreaming을 우리 하네스에 넣을 만한지 분석한 묶음이다. dreaming은 끝난 세션의 대화 기록을 나중에 다시 읽어, 다음 세션이 볼 메모를 고쳐 쓰는 배치 작업이다. [기존 검토](../dreaming/index.md)의 출처 목록에 있는 원문만 다시 읽고, 이 하네스를 쓰는 jobtailor 프로젝트의 기록으로 직접 재서 따로 판단했다(2026-11-11).

dreaming을 통째로 들이는 것은 맞지 않는다. 끝난 작업의 워커·검증자 기록을 뒤에 읽는 회고로는 쓸 만하다. 그 결과는 세션에 바로 주지 말고, 사람이 골라 지침·검사·hook으로 올릴 후보 목록으로 쓴다. 하루치 기록으로 시험해 보니 손으로 찾은 함정 13가지 중 11~12가지를 $7~8에 찾았다. 다만 메모의 3분의 2는 이미 있는 내용이었고 틀린 줄도 섞였다. 메모가 다음 세션을 돕는지는 재지 못했다.
