# 하네스 문서

하네스 규칙의 근거, 검증 기록, 검토 자료다. 규칙 자체는 `core/`의 지침과 스킬에 있고, 여기에는 왜 그렇게 정했는지와 바꿀지 판단할 재료를 둔다.

| 문서 | 다루는 주제 | 언제 읽는가 |
| --- | --- | --- |
| [정책 근거](policy/index.md) | 컨텍스트 정책의 근거·검증 결과, 규칙별 강제 수단과 제거 시험 | 컨텍스트 정책이나 규칙을 바꾸기 전, 도구 버전이 바뀌어 다시 검증할 때 |
| [Dreaming·지식 위키 검토](dreaming/index.md) | 세션이 바뀔 때 배운 것을 남기는 방법(dreaming)과 지식 위키를 우리 하네스에 쓸 수 있는지 검토 | 세션 사이에 기억을 남기는 장치를 넣을지 정하거나, 그 작업을 시작하기 전 |
