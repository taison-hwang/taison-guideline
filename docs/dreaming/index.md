# Dreaming·지식 위키 검토

Anthropic이 공개한 두 자료를 우리 하네스에 쓸 수 있는지 따져 본 결과다(2026-11-09).

- **dreaming**: 지난 대화 기록을 나중에 다시 읽고, 다음 세션이 참고할 메모를 고쳐 쓰는 작업.
- **knowledge-wiki**: 문서 묶음을 한 번 읽어 위키(작은 메모 파일 모음)로 만들고, 질문이 오면 위키에서 답하는 방식.

**결론**: 두 자료를 그대로 가져오지는 않는다. 우리 하네스에 실제로 빠진 것은 하나뿐이다. 작업을 끝내고 `/clear`하면 그 세션이 작업하며 배운 것(실패한 방법과 이유, 함정, 겨우 찾아낸 명령어)이 모두 사라진다. 이것을 받아 둘 곳이 없다. 이 부분에만 두 자료의 메모 쓰는 규칙을 빌려 오고, 먼저 효과가 있는지 재 본 뒤에 조금씩 넣는다.
